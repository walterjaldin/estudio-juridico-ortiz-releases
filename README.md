# Estudio Jurídico Ortiz y Asociados — Instaladores

Este repositorio solo contiene los instaladores de la aplicación (no el código).

## Instalar por primera vez
1. Abra **[la última versión](../../releases/latest)**.
2. Descargue el archivo que termina en **`-setup.exe`** y ejecútelo.
3. Si Windows muestra *"Windows protegió su PC"*: **Más información → Ejecutar de todas formas**.

## Actualizaciones
No necesita volver aquí: la aplicación avisa sola cuando hay una versión nueva.
